fluxharness

Eval Harness

An open-source testing tool that decides whether an AI agent is ready to ship. Three agents (Scout → Architect → Critic) pass typed, checked results to each other; ten deterministic checks score first, a separate larger model judges composition and taste, and a saved baseline turns "it worked once" into a regression check. 31 tests, no API key needed. A deliberately weakened copy of the workflow scores 0.000: the rig catches the regression it was built to catch.
