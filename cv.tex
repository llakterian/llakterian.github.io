\project{C. Sambu Farm Manager: Full-Stack Farm Management PWA}
  {\href{https://cs-farm-api.llakterian.workers.dev}{Live API}}
\small
Comprehensive PWA for managing a multi-sector Kenyan agribusiness (tea, dairy, avocado, poultry). Features a variable payroll engine supporting piece-rate (KES 9/kg), day-rate (KES 216/day), and prorated salary modes, production logging across 5 sectors, expense tracking, domestic loan management, real-time weather intelligence (Open-Meteo, 14 Kenyan farming regions), and factory-level financial reporting with CSV export. Migrated from local IndexedDB/FastAPI/Docker to serverless Cloudflare Workers + D1. Implements JWT auth, column-whitelist SQL injection defense, Workbox-powered offline caching with "Add to Home Screen" PWA support, and print-optimized report layouts. Tech: React 18, Tailwind CSS, Hono.js, Recharts, Headless UI, vite-plugin-pwa.
